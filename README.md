这是一些随手用Codex制作的单文件html小工具，以下是针对每一个小工具的详细介绍：
# 1. 干瞪眼计分器
“干瞪眼”是一种简单易学、节奏明快的扑克牌玩法。玩家按规则接牌，争取最先出完手中的牌；接不上时，就只能看着别人出牌，“干瞪眼”的名字也由此而来。它既考验运气，也讲究记牌和出牌时机，很适合朋友聚会、家庭休闲时一起玩。
该计分器专为这种玩法设计，预先设置好底分(即每张牌的分数)以及输分上限(可调)后，每一局结束(即有一名玩家手牌出尽)时，输入输家各自手中剩余的牌数，叠加“炸弹”造成的分数翻倍以及“全关”(即该玩家最终手牌数为初始数量)倍率，输家减去各自对应分数，赢家获得输家减去分数的总和分数，取最后分数最高者为最终胜利。
最新版本中针对手机端用户进行了UI交互优化，现在于手机端打开计分器时，网页下方会显示内置的功能小键盘，方便快捷地输入分数、炸弹数量及进行结算操作。
# 2. 简易收银程序
专为校内游园会/义卖的场景设计，界面分为收银台总操作端、后厨端及宣传屏端。理想情况下，一台MacBook通过“随航”扩展屏幕至一台iPad上以显示后厨屏，并通过有线方式连接到另一块面向客户的宣传屏，内置显示器为总操作端。总操作端可以进行商品增减、账本查看及导入导出、宣传屏照片设置、电子支付码设置、结算订单等操作；当总操作端将商品加入购物车时，宣传屏端会同步显示购物车内商品，总操作端点击对应支付方式的结算时，宣传屏上会弹出显示最终金额、找零金额或收款码的模态框。总操作端确认收款之后，订单会发送到后厨端窗口，后厨随后即可根据订单制作商品，并根据订单号找到对应客户进行交付。
# 3. 英语单词矩阵检测
为英语老师设计的课堂互动小工具，在一个方形矩阵中找出设置好的单词，有横向、纵向交错排列，加油吧～
# 4. 打字学习小助手
为低年级段学生设计的拼音学习小工具，也可同时学习一定的打字技巧。界面显示一个汉字，玩家输入对应正确的输入码即视为正确。
# 5. 六一快乐糖果雨、六一知识小火箭
为低年级段学生设计的儿童节班级活动互动小工具。前者为纯粹趣味性的反应力闯关，后者则设置了多学科题库进行答题。两者均考虑设置了较强的鼓励机制。
# 6. 原神祈愿模拟器
还原了《原神》游戏内真实的祈愿概率算法，还原了所有机制(包含但不仅限于大小保底、捕获明光等)。尽可能给到玩家和游戏内接近的抽卡体验。现已加入根据玩家现有资源进行大数量级抽卡模拟，并计算获得当期UP角色的概率的功能。欢迎体验试用并提出后期进一步的功能改进建议～
