## 开始使用与数据保存

推荐从在线首页进入，并使用较新的浏览器。也可以下载对应 HTML 文件，用浏览器打开；无需安装应用或构建项目。下载后的首页导航需要同目录下的工具文件才能正常跳转。

收银系统建议通过在线页面使用，方便管理多窗口和本地存储。课堂小游戏建议先在实际使用的电脑、投影或触屏设备上试一轮。

| 工具 | 数据保存方式 | 备份或导出 |
| --- | --- | --- |
| 干瞪眼计分器 X beta | 当前浏览器本地保存玩家、设置和已入账流水 | 复制或分享战绩文本 |
| 收银记账系统 v4.0 | 当前浏览器本地保存商品、订单、账本及设置 | 导出 JSON，可再导入 |
| 原神祈愿模拟器 v2 | 当前浏览器本地保存祈愿状态、统计及设置 | 资源预测的逐轮结果可下载 CSV |
| 单词矩阵、打字练习、两个六一游戏 | 当前页面中的临时状态 | 无持久化成绩记录 |

本地保存的数据不会自动同步到其他设备、浏览器或域名。在线页面与下载后打开的文件也不应视为共享数据；清理浏览器数据后，记录可能丢失。收银活动结束后建议导出备份，计分结束后建议复制战绩。

## 1. 干瞪眼计分器

“干瞪眼”是朋友聚会中常见的扑克牌玩法。本工具负责根据每局剩余手牌、炸弹数和全关情况计算分数，并累计整场战绩。

**推荐版本：** [X beta 手机版](https://joshzhangzzx.top/JustLookX_v2_compact_keypad_selectfix.html)。以下操作以此版本为准。

### 使用步骤

1. 点击玩家姓名修改名字，使用“+ 玩家”增加参与者。
2. 打开右上角齿轮，设置每张牌的底分；需要时启用“输分封顶”并填写支出上限。
3. 每局结束后，填写所有在线玩家的剩余牌数：赢家填 **0**，其他玩家填 **1～5**。
4. 设置本局的**炸弹总数**，点击“开始结算”。
5. 在“本局清算”中核对金额；有误时选择“返回修改”，正确后点击“收钱入账”。
6. 查看累计分数、排名及实时流水；整场结束后用“复制分享”保存战绩。

暂时不参加的玩家可切换为“小憩”，该玩家不参与本局结算。误记的单局可在流水中删除，累计分数会重新计算。“重置全场”会清除本场记录，使用前先保存需要的战绩。

### 计分规则

- 每个炸弹使本局倍率翻倍，即炸弹倍率为 `2^炸弹数`。
- **剩 5 张自动视为全关，再乘 2**。当前版本按固定的 5 张判断，不会根据不同发牌规则自动调整。
- 输家扣分 = 剩余牌数 × 底分 × 炸弹倍率 × 全关倍率。
- 开启封顶后，每位输家的扣分分别受支出上限约束。
- 赢家获得所有输家扣分的总和；如果多位在线玩家都填 0，系统会平分赢分。通常只应给实际赢家填写 0。

例如：底分为 1、本局有 1 个炸弹，甲剩 2 张、乙剩 5 张、丙出完。未启用封顶时，甲扣 4 分，乙因全关扣 20 分，丙加 24 分。

### 手机与电脑操作

手机窄屏下，点击玩家的牌数区域后，使用页面底部专用小键盘输入；键盘同时提供上一位、下一位、炸弹增减及结算按钮。

电脑端在牌数输入框中按 Enter 可切到下一位，最后一位按 Enter 打开结算；在该输入框中按 `=` 增加炸弹、按 `-` 减少炸弹。

**保存范围：** 已确认入账的流水、玩家和设置会本地保存；当局尚未入账的牌数与炸弹数不会作为完整草稿保存。战绩分享是文本分享，不是可导入的数据备份。

## 2. 收银记账系统

面向校内游园会、义卖等场景，提供收银台、后厨屏与宣传屏三个工作窗口。

**推荐文件：** [CashierV4.0.html](CashierV4.0.html)。首页将它标为 v4.0，目前页面内部标题和导出数据的版本号仍为 **v3.6.4**；本文介绍的是这个文件中的三屏功能。

### 开摊前准备

1. 打开“商品管理”或“新增商品”，填写商品名称与价格。
2. 在“设置”中上传微信、支付宝收款码；需要宣传画面时上传海报。
3. 点击“后厨屏”和“宣传屏”，允许浏览器弹出窗口。
4. 将收银台留在操作屏，把后厨和宣传窗口移动到相应扩展显示器。
5. 先完成一笔试单，检查金额、收款码、订单同步和后厨完成操作。

三屏指**同一浏览器打开的多个窗口**，适合一台电脑连接多块显示器。例如，MacBook 的内置屏作为收银台，通过随航扩展的 iPad 显示后厨，再连接一块面向顾客的宣传屏。当前工具没有跨设备联网订单服务，分别在不同设备打开网址不会自动组成三屏系统。

### 每笔订单怎么操作

1. 点击商品卡片加入当前订单，调整数量；按需添加商品备注，例如“少糖”“分开装”。
2. 使用“减 1”“减 2”“减 5”或自定义优惠，核对应收金额。
3. 选择现金、微信或支付宝。现金支付填写实收金额，查看找零；电子支付会在宣传屏展示对应收款码。
4. **核实已收到款项，再执行确认收款。** 选择支付方式只会展示收款信息，尚未完成订单。
5. 完成收款后，订单写入账本并发送到后厨屏。
6. 后厨根据订单制作商品，按订单号交付，并将订单标记完成。

宣传屏会同步展示购物车及收款信息，空闲时可展示海报或欢迎画面。二维码仅用于展示，系统不会自动核验微信或支付宝的实际到账状态。

### 快捷键

在收银台页面、没有正在编辑文字的情况下：

| 按键 | 操作 |
| --- | --- |
| S | 定位最近加入商品的数量输入框 |
| B | 定位最近加入商品的备注输入框 |
| Y | 添加 1 元优惠 |
| Enter | 按当前操作状态确认输入或推进结算 |

Enter 的作用随所在输入框和结算阶段变化，操作时以页面显示为准。

### 账本与备份

- 在“今日账本”中查看交易记录和收入汇总。
- “导出数据”生成 JSON 文件，包含商品、购物车、交易记录、后厨订单、订单号、收款码和宣传屏设置。
- “导入数据”会覆盖当前业务数据；如果备份包含收款码，页面会另行询问是否覆盖现有收款码。导入前先导出当前数据。
- “清空业务数据”会清除商品、购物车、交易记录及后厨订单，并重置订单号，收款码保留。

导出的文件可能包含收款码图片，保存或分享时请确认其中内容。旧版与当前版的导入兼容性未作完整验证，换版本前先备份。

如果后厨屏或宣传屏没有打开，检查浏览器是否拦截弹窗。使用中保持收银台窗口打开；如显示未同步，可重新从收银台打开对应窗口。

## 3. 英语单词矩阵寻宝

为英语课堂设计的单词寻找工具。目标单词藏在字母矩阵的横向或纵向，学生在倒计时内找出全部单词。

**入口：** [打开工具](https://joshzhangzzx.top/EngWrdSqrV2.html)

### 使用步骤

1. 打开页面，默认词库为 APPLE、BANANA、ORANGE、CHERRY，倒计时设置为 60 秒。
2. 点击“设置词库与时间”，输入本次要练习的单词。单词之间用空格、换行、英文逗号或中文逗号分隔，系统会转换为大写。
3. 设置倒计时秒数，点击“应用并开始”，生成新的字母矩阵。
4. 找到目标单词后，**先点首字母，再点末字母**。两个端点必须在同一行或同一列，不需要拖动。
5. 正确选中的单词会高亮，待找列表中的对应项目会标记完成。全部找齐或时间耗尽时结束。

页面提供“暂停”“继续”和“重置”；“重置”会按当前词库与时长重新生成矩阵。

**当前版本的计时限制：** 初始化和重置后，代码没有正确启动倒计时，页面可能停留在初始时间。可先点“暂停”，再点“继续”启动计时；重新应用设置或重置后也需如此操作。需要严格限时的课堂活动，建议先确认数字正在倒数。

例如，可输入 `APPLE BANANA ORANGE CHERRY`，并设置 120 秒用于小组挑战。词库建议使用不重复的英文单词；设置和挑战进度仅保留在当前页面，刷新后恢复默认。

## 4. 打字学习小助手

面向低年级学生，用“看汉字、输入拼音”的方式练习拼音拼写与键盘输入。每轮随机抽取 10 个不重复的汉字。

**入口：** [打开工具](https://joshzhangzzx.top/TypingExerciser.html)

### 使用步骤

1. 使用配有实体键盘的设备打开页面，并把输入法切到英文输入。
2. 观察显示的汉字，直接键入不带声调的拼音字母，例如“学”输入 `xue`。
3. 按 Backspace 删除最后一个字母，按 Enter 提交答案。
4. 答对后自动进入下一题；答错时会显示正确拼音，清空输入后继续尝试当前题。
5. 完成 10 题后，点击“再玩一次”开始新一轮。

“绿”的拼音输入为 `lv`，以字母 v 表示 ü。当前页面通过实体键盘按键接收输入，没有用于唤起手机软键盘的文本输入框。

### 得分规则

每次答对得 10 分；连续答对达到 3 次后，每次继续答对额外加 5 分。答错会清零连续正确次数。提交后等反馈结束再继续操作，得分和进度不作持久化保存。

## 5. 六一快乐糖果雨

适合儿童节班级活动的反应力小游戏：移动小篮子，在 60 秒内接住落下的物品。

**入口：** [打开工具](https://joshzhangzzx.top/61game_1_v1.1.html)

### 怎么玩

1. 点击“开始游戏”。
2. 电脑端按左右方向键，或移动鼠标控制篮子；触屏设备可通过手指滑动控制。
3. 接住糖果、星星、蛋糕、气球和礼物，累计分数。
4. 倒计时结束后查看成绩，点击“再玩一次”重新挑战。

| 物品 | 得分 |
| --- | --- |
| 糖果、棒棒糖 | 1 分 |
| 星星、蛋糕、气球 | 2 分 |
| 礼物 | 5 分 |

每连续接住 5 个物品，额外奖励 3 分；漏接会中断连击。随着时间推进，物品下落逐渐加快。成绩只用于当前一轮，不会保存历史排行榜。

## 6. 六一知识小火箭

面向低年级学生的多学科答题游戏。答对题目，小火箭就会升得更高；答错或超时也会给出答案与鼓励。

**入口：** [打开工具](https://joshzhangzzx.top/61game_2_v1.html)

### 怎么玩

1. 点击“开始挑战”。
2. 阅读题目，点击三个选项之一，或按键盘 **1、2、3** 选择对应答案。
3. 每题限时 **20 秒**。查看答题反馈后，系统自动进入下一题。
4. 完成 **10 题**后查看答对题数、总分和称号，点击“再玩一次”重新挑战。

每轮包含 5 道 100 以内加减法、2 道语文题、2 道常识题和 1 道趣味题，题目与选项顺序会随机排列。

答对得分为 **10 分 + 作答时剩余秒数**；答错或超时不得分，并展示正确答案。成绩仅保留在当前页面，没有历史成绩记录。

## 7. 原神祈愿模拟器

提供角色活动祈愿的单抽、十连体验，以及基于现有资源的 UP 五星获得概率预测。

**推荐版本：** [v2](https://joshzhangzzx.top/GenshinSimulator_v2.html)

### 常规祈愿模拟

1. 点击右上角齿轮，选择五星 UP 和三名不同的四星 UP。
2. 如果想接续现有状态，填写五星、四星垫抽数，以及各自的大小保底状态和小保底连续歪次数。
3. 点击“保存全部配置”，在“常规祈愿模拟”中进行单抽或十连。
4. 查看五星与四星水位、累计祈愿、本轮追 UP 抽数和统计结果。鼠标悬停或触屏点按抽取结果，可查看该抽触发的机制。

垫抽数表示当前角色活动池中距上次对应星级结果的抽数。四星水位同时计入角色和武器：获得任意四星物品时重置；如果五星顶掉四星保底，四星保底会顺延。

齿轮设置中还可管理角色和武器列表，添加自定义角色时选择对应元素。“重置 UP 卡池”读取当前 HTML 源码中的默认 UP，保存后生效，保留祈愿记录及自定义列表；它不会联网获取游戏最新卡池。“重置祈愿记录”是另一项操作。

### 资源规划与出金预测

1. 切换到“资源规划与出金预测”。
2. 填写五星、四星垫抽数，大小保底状态与小保底连续歪次数。
3. 填写纠缠之缘、原石、无主的星辉、无主的星尘，以及本月剩余星尘兑换次数。
4. 按账号角色持有情况选择星辉返还估算：保守、常规或高命。
5. 设置独立模拟次数，点击“开始独立模拟”。页面建议 100,000 次；设备较慢时可先用较小次数试算。
6. 查看成功概率、成功轮次平均出 UP 抽数、中位数、平均回收抽数及频率分布。
7. 可切换每 5、10 或 20 抽的分布区间，并下载详细结果 CSV 查看逐轮结果。

每轮都从相同初始状态开始，直到获得一个当期 UP 五星或资源用尽；不是连续沿用上一轮的结果。模拟会将抽取返还的星辉、星尘继续兑换纠缠之缘：星辉按 5:1，星尘按 75:1，并受填写的当月剩余兑换上限约束。

星辉返还受角色持有情况和命座影响，因此结果也取决于所选估算档位。成功轮次的平均出 UP 抽数只统计成功轮次，不包含资源耗尽仍未获得 UP 的轮次。重复运行的结果会有随机波动。

### 概率与数据说明

当前实现包含五星和四星保底、大小保底、捕获明光及资源回收。页面内“概率与机制说明”列出了具体模拟规则。

这是**非官方概率模拟工具**。官方没有公开完整服务器代码、逐抽软保底曲线及全部池内权重，工具对未公开部分采用社区统计拟合，不代表与游戏服务器实现完全一致，也不保证真实账号的抽取结果。

祈愿状态、统计和设置保存在当前浏览器，不会自动读取或同步游戏账号。CSV 导出用于资源预测结果分析，不是完整祈愿记录和配置的恢复备份。
